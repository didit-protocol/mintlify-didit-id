The Didit holder wallet is the holder app for Didit ID. Holders use it to claim credentials, keep them protected with passkeys, and present only the claims a verifier requests.

The wallet speaks [OpenID4VCI](/concepts/openid4vci) to claim credentials and [OpenID4VP](/concepts/openid4vp) to present them. It never needs a tenant API key. It calls public holder and verifier protocol endpoints.

## What the wallet does

- **Claims credentials.** Open an email claim link, review the offer, enter the transaction code when required, and receive an SD-JWT VC through OpenID4VCI.
- **Protects credentials with passkeys.** Sign in and approve wallet actions with a passkey-capable browser.
- **Supports selective disclosure.** Review the relying party and requested claims before presenting.
- **Presents credentials.** Submit an OpenID4VP `vp_token` to the verifier flow and return only approved disclosures.
- **Stays protocol-native.** Use SD-JWT VC, OpenID4VCI, OpenID4VP with DCQL, and Token Status List checks.
