---
title: "Issue via email"
description: "Send a credential offer as an email claim link — the holder opens the link, enters the transaction code, and claims the credential into their wallet."
---

This guide will cover email-delivered issuance: creating a credential offer with `recipient_email` and `send_email: true` so Didit ID emails the holder a claim link, how the link opens the holder wallet, and how the transaction code (PIN) protects the exchange — including when to share it out-of-band and when to disable it.

<Note>Content lands with the wallet release.</Note>
